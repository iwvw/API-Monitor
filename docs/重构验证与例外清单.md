# 重构验证与例外清单

最后更新：2026-07-07

本文件记录允许的例外，避免未来的 AI 审计反复把有意偏离 Kumo-only 规则的行为当作违规上报。新增例外应当收窄范围、明确命名，并在 Kumo 或项目代码提供正确替代时移除。

## 允许的 UI 例外

| 区域 | 文件 | 原因 | 后续规则 |
|------|------|------|----------|
| 品牌颜色 | `src/js/components/ui/BrandIcon.jsx`、生成的 `src/css/simple-icons.css` | 外部品牌身份颜色无法用 Kumo 语义 token 表达而不丢失含义。 | 仅限品牌图标渲染使用，不要把这些颜色复用到通用 UI 外观上。 |
| 二维码颜色 | `src/js/pages/FileboxPage.jsx`、`src/js/pages/VoidRoomPage.jsx` | 二维码深/浅色和白色二维码背景是对比度功能需求。 | 颜色只保留在二维码生成或二维码图片展示本地。 |
| 摄像头/扫码器表面 | `src/js/pages/TotpPage.jsx` | 扫码预览用黑色作为内容表面，不是主题色。 | 不要扩展到周围 UI。 |
| 终端颜色 | `src/css/app.css`、`src/js/pages/ServerPage.jsx` | 当 Kumo CSS 变量不可用时，xterm 兜底颜色是可读性兜底。 | 优先使用 Kumo 变量；原始兜底值只能放在 `getKumoToken` 或 CSS 变量兜底之后。 |
| 媒体预览表面 | `src/js/pages/DnsPage.jsx` | 视频预览和内嵌文档预览需要黑/白内容背景。 | 这些颜色只保留在媒体表面上。 |
| 遗留 ECharts 颜色 | `src/js/pages/UptimePage.jsx` | 现有 ECharts options 包含原始主题颜色，暂作为已接受的遗留例外。 | 触碰 uptime 图表时，向 Kumo `TimeseriesChart`、`Meter` 或 `ChartPalette` 迁移。 |
| 地图状态/气泡颜色 | `src/js/components/server/ServerLocationMap.jsx` | ECharts 地图需要硬编码十六进制值来表示表示状态的数据点/气泡。 | 颜色只保留在地图渲染或图例中。 |
| 原生文件选择器 | 任意页面 | 浏览器文件选择可能需要原生隐藏 file input。 | 保持 input 隐藏或仅屏幕阅读器可见，并用 Kumo `Button` / `Input` UI 触发它。 |
| 远程系统键盘桥接 | `src/js/pages/RemoteDesktopPage.jsx` | 移动浏览器需要焦点落在真实原生文本控件上才能唤起系统键盘和 IME。 | 保持 textarea 隐藏，只通过可见的 Kumo `Button` 暴露；远程文本仍走 P2P 控制通道。 |
| 二维码对比色 | `src/js/pages/FileboxPage.jsx` | 二维码 `color: { dark, light }` 是对比度功能需求。 | 限定在 QRCode 生成参数内。 |
| GitHub 流程点/边缘颜色 | `src/js/pages/GitHubPage.jsx`、`src/js/pages/PublicGitHubPage.jsx` | 工作流状态点与可视化边缘需要原始色相区分；点状态色优先使用 Kumo 语义色，SVG 边缘十六进制值仅作图元绘制。 | 状态点类应继续用 `bg-kumo-success/danger/warning/info`；边缘色只在地图类 SVG 内使用。 |
| 公开页主题色存储 | `src/js/modules/publicPageBranding.js` | 用户自定义的公开页强调色需要以原始值持久化。 | 仅限用户偏好值，复用值仍走 Kumo token。 |
| 危险确认对比文字 | `src/js/pages/GitHubPage.jsx`、`src/js/pages/ApiDocsPage.jsx`、`src/js/pages/SettingsPage.jsx` | `!bg-kumo-danger` 危险确认按钮上的白字用于对比度。 | 仅在与 `bg-kumo-danger`/状态块配对时使用。 |
| 紧凑选择行按钮 | `src/js/pages/DrawioPage.jsx`、`src/js/pages/PublicGitHubPage.jsx` | 自绘多行/紧凑列表行按钮承载复制的 icon+文案或运行列表选择，视觉密度高于标准单行 `Button`。 | 仅限多行内容行；普通按钮仍用 Kumo `Button`。 |
| Ask AI 侧栏遮罩 | `src/js/components/adminai/AskAiPanel.jsx` | 右侧滑出面板的半透明遮罩，PRD 明确指定 `bg-black/30`。 | 仅限遮罩层本身，不要扩展到侧栏内部。 |
| Ask AI 消息气泡对比文字 | `src/js/components/adminai/MessageList.jsx` | `bg-kumo-brand` 用户消息气泡上的白字用于对比度。 | 仅在与 `bg-kumo-brand` 气泡配对时使用。 |
| Ask AI 云朵动画颜色 | `src/css/app.css` | Cloudflare 风格云朵动画的渐变橙色（`#FFF`、`#FFEDDD`、`#FF9335`、`#FFB371`）是 Cloudflare 官方品牌色，CSS 渐变无法用 Kumo token 表达。 | 仅限 `.askai-cloud-node-*` 类内的云朵渲染使用。 |

## 验证清单

- 涉及 UI 的改动后运行 `npm run ui:governance`。
- 大规模 AI 交接或较大的 PR 前运行 `npm run audit:fast`。
- 需要新增硬编码颜色时，先在本文件登记窄范围原因，再更新扫描器白名单。
- 触碰破坏性删除流程时，优先使用 `dialog.deleteResource` / Kumo `DeleteResource`。
- 触碰大型页面时，只拆分相关的常量、hooks、弹窗、表格或面板，避免整文件重写。
