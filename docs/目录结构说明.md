```
│   ├── cloudflare/          # Cloudflare 模块
│   ├── serveragent/         # Agent 服务器
│   ├── openai/              # OpenAI 模块
│   ├── geminicli/           # Gemini CLI 模块
│   ├── qwen/                # 通义千问模块
│   ├── aliyun/              # 阿里云模块
│   ├── tencent/             # 腾讯云模块
│   ├── koyeb/               # Koyeb 模块
```

```
agent-rust/

│   ├── main.rs              # Agent 主程序
│   ├── config.rs            # 配置管理
```

**职责**:

## 🏗️ 开发与生产环境

### 开发环境

```
前端: npm run dev           → Vite 开发服务器 (localhost:5173)
后端: go run ./cmd/api-monitor → Go 后端 (localhost:3000)
Agent: cargo run            → Rust Agent
```

### 生产环境

```
构建:
  npm run build             → 生成 dist/
  go build -o api-monitor   → 生成可执行文件
  cargo build --release     → 生成 Agent

部署:
  Docker Compose            → 一键部署
  或手动启动 api-monitor.exe
```

## 📝 目录命名规范

- **驼峰命名**: React 组件 `DashboardPage.jsx`
- **模块名**: 与功能对应 `cloudflare/`, `serveragent/`
