# 卡片式图块看板 —— 尺寸适配规范

- 制定日期：2026-09-05
- 适用范围：`src/js/components/tiles/` 组件库 + 所有图块内容组件
- 目的：统一不同尺寸档位下卡片内部元素/功能的取舍规则，避免各卡自行其是导致拥挤、错位、溢出

## 1. 档位定义

按图块在网格中的宽高（RGL 单位：w 列数，h 行数）划分四个档位：

| 档位 | 条件 | 典型尺寸（约） | 用途 |
|---|---|---|---|
| `half` | h ≤ 1 | 233×106 | 半高统计条，两张可上下叠放占一个单元 |
| `compact` | w == 1 && h == 2 | 233×225（1×1 方块） | 迷你图/单指标 |
| `full` | w ≥ 2 && h ≤ 2 | 478×225 ~ 满宽 | 标准横卡（图表完整） |
| `rich` | h ≥ 4 | 478×464 | 双高富内容（摘要/明细） |

档位判定函数（页内 `tileDensity(w, h)`）：
`h<=1 → half`；`h>=4 → rich`；`w>=2 → full`；否则 `compact`。

### 宽度分档（拉宽时信息密度递增，禁止单纯拉伸留白）

在高度档位之上叠加宽度档：`widthTier(w)`：`w>=4 → wide`；`w>=2 → medium`；否则 `narrow`。

| 宽度档 | 数值行显示 | 适用 |
|---|---|---|
| `narrow`（1 列） | 主值 + 环比 | 1×1 / 1×2 |
| `medium`（2~3 列） | + 日均 / 峰值 | 2×1 / 2×2 / 2×4 |
| `wide`（≥4 列） | + 今日（或负载/核数等维度） | 4×1 / 4×2 |

- 数值行统一走 `ValueStatBar`（`src/js/pages/TilesDemoPage.jsx`）：half 且 narrow 时垂直居中防溢出，其余横向 baseline 对齐，统计项 `whitespace-nowrap` 不换行。
- 半高卡随宽度档同步丰富（`HalfTile` 三形态）：1 列 = 三行（标题/数值/分数据）；2 列 = 左数据右 mini 缩略趋势图；≥4 列 = 左侧数据 + 右侧贴边缩略图（**禁止图放到底部**，一律左右结构）。
- 半高卡内容区统一 `pb-1.5` 底部留白，禁止内容贴底边。

## 2. 元素可见性总表

| 内容元素 | half | compact | full | rich |
|---|---|---|---|---|
| 主数值 + 环比（StatValue） | ✓ | ✓ | ✓ | ✓ |
| 附加统计（日均/峰值/今日等，按宽度档） | ✓（按宽度档） | ✗ | ✓（按宽度档） | ✓（按宽度档） |
| 图表（TileChart） | ✗ 隐藏 | 贴边 sparkline（无坐标轴） | 完整图表（轴 + 网格） | 完整图表（同 full，更高） |
| 副数值（TTFB / 缓存命中等） | 窄档垂直/宽档并排小字 | 仅主值 | ✓ 随卡 | ✓ |
| 明细/列表/点阵 | 1 行 truncate / 4 点 | 精简（6 点） | 完整（8 点） | 完整 + 状态说明行（10 点） |
| 仪表（MiniMeter / CompactMeter） | 双行紧凑仪表（label+细条+值），拉宽显示用量详情 | 双仪表纵向 | 双仪表纵向 | 双仪表纵向 + 主机名等补充 |

## 3. 元素细则

### 3.1 数值行（StatValue / ValueStatBar）
- 所有档位：大数值（text-2xl）+ 环比徽标（↗ 绿 / ↘ 红）。
- `half` 档空间紧张时允许降到 text-xl，且与标签/单位并排。
- 附加统计项（日均/峰值/今日等）按宽度档递增，统一 `ValueStatBar` 渲染，禁止 justify-between 拉空留白。

### 3.2 图表 TileChart
- `half`：不渲染图表，卡片垂直居中只显示数值区。
- `compact`：`density="compact"` —— 贴边 sparkline（grid 0,0,2,0，隐藏坐标轴与网格）。
- `full/rich`：`density="full"`/`density="rich"` —— 坐标轴 + 浅网格（rich 高度更大，图表随之变高）。
- 所有档位：背景透明、隐藏坐标轴线、`setOption(..., true)` 防止档位切换残留样式。

### 3.3 摘要行
- 仅 `rich` 档显示（如「峰值 X · 日均 Y」），`half` 档最多一行 10px 小字，其余档隐藏。

### 3.4 双序列（延迟/TTFB 类）
- `half`：narrow 垂直两行（主值 + TTFB 小字），宽档并排双值。
- `compact`（1×2）：仅主数值。
- `medium/full`：双数值 + 图例色点 + 双线图；`wide/rich` 再追加 延迟日均/峰值。

### 3.5 仪表 MiniMeter / CompactMeter
- `half`：内存 + 磁盘双行紧凑仪表（`CompactMeter`，单行 label + 细进度条 + 值）；拉宽（≥2 列）时值列显示具体用量（used/total）。
- `compact/full`：`MiniMeter` 双仪表纵向（含用量详情）。
- `rich`：双仪表纵向 + 补充信息行（主机名）。

### 3.6 状态点阵（可用率类）
- `half`：4 点；`compact`：6 点；`full`：8 点；`rich`：10 点 + 状态说明行。

### 3.7 布局骨架（所有卡统一）
```
<div class="flex h-full min-h-0 flex-col overflow-hidden {half 无整体 px，内容由 HalfTile 管理；非 half: px-4 pt-1}">
  {half: HalfTile（tier 三形态）}
  非 half:
    数值行 ValueStatBar（shrink-0，按宽度档带附加统计）
    图表/内容区（min-h-0 flex-1，-mx-4 出血到卡边）
  bottom 明细/点阵（按档位，内容区 pb-1.5 防贴边）
</div>
```
- half 档内容统一走 `HalfTile`：narrow = 三行（TileFrame 标题做名称行 / 数值居中 / 底部单行分数据）；medium、wide = 左数据右图（右侧图贴右边缘 `-mr-4`），禁止图沉底。
- 数值行始终在最上（half/compact 时视觉上垂直居中）。
- 图表区 `-mx-4` 出血至卡片左右边缘（对齐 Cloudflare 官方）。

## 4. 各卡片档位矩阵

| 卡片 | half | compact | full | rich |
|---|---|---|---|---|
| API 请求/令牌、OpenAI 请求/错误、主机 CPU、CF Zone | 数值 + 环比，宽度档追加日均/峰值/今日 | 数值 + sparkline | 数值 + 完整图 + 宽度档统计 | 数值 + 完整高图 + 宽度档统计 |
| OpenAI 延迟 | narrow 垂直双值 / 宽档并排双值 | 主值 + 图 | 双值 + 图例 + 双线图 | 同上 + 延迟日均/峰值 |
| 内存/磁盘 | 双仪表并排 | 双仪表纵向 | 双仪表纵向 | 双仪表纵向 + 主机名 |
| 可用率 | 数值条 + 4 点 | + 6 点 | + 8 点 | + 10 点 + 状态说明 |
| 统计小卡（服务器/PaaS/DNS/文件柜/TOTP/调度/状态页） | 图标 + 标签与数值并排 + 1 行明细 | 竖排：图标行 + 大数值 + 明细 | 同 compact | 同 compact（数值加大、间距放宽） |

## 5. 实现约束
- 档位判定统一走 `tileDensity`，卡内不得自行用 w/h 推断。
- 所有间距用 kumo 尺寸系统，`half` 档禁止弹窗/多行明细等占空间元素。
- 内容超长一律 `truncate`，禁止换行撑破卡片。
