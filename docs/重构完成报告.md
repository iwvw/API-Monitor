### 4. 前端优化

**创建统一 API 客户端**:
```javascript
// src/js/modules/api-client.js (新建)
import api from '@/js/modules/api-client.js';

// 标准化调用
const data = await api.get('/api/servers');
const result = await api.post('/api/servers', { name: 'test' });

// 统一错误处理
try {
  await api.delete('/api/servers/1');
} catch (error) {
  if (error instanceof api.ApiError) {
    console.log(error.status, error.message);
  }
}
```

**优势**:
- ✅ 统一认证头注入
- ✅ 标准化错误处理
- ✅ 自动显示错误提示
- ✅ 支持静默模式

### 5. 后端优化

**移除 legacyproxy**:
```diff
- import "github.com/iwvw/api-monitor/backend-go/internal/legacyproxy"
- legacy *legacyproxy.Adapter
- legacy, err := legacyproxy.New(cfg.LegacyBaseURL)
- s.legacy.ServeHTTP(w, r)

+ // 直接返回 404
+ response.Error(w, http.StatusNotFound, "路由未找到")
```

**优势**:
- ✅ 代码更简洁
- ✅ 减少依赖
- ✅ 性能提升
- ✅ 错误更清晰

1. **Go 编译依赖**
   - 确保 Go 1.23+ 已安装
   - 运行 `go mod download` 下载依赖

2. **前端 API 调用**
   - 部分页面可能仍使用旧的 fetch 方式
