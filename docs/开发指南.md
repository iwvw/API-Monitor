## 快速开始

### 环境要求

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| **Node.js** | 18+ | 前端开发与构建 |
| **Go** | 1.23+ | 后端开发 |
| **Rust** | 1.70+ | Agent 开发 (可选) |
| **Git** | 任意 | 版本控制 |

### 克隆项目

```bash
git clone https://github.com/iwvw/api-monitor.git
cd api-monitor
```

### 前端开发

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 访问 http://localhost:5173
```

### 后端开发

```bash
# 1. 进入后端目录
cd backend-go

# 2. 下载 Go 依赖
go mod download

# 3. 构建
go build -o api-monitor.exe ./cmd/api-monitor

# 4. 运行
./api-monitor.exe
# 默认监听 http://localhost:3000
```

### 一键启动 (Windows)

```bash
# 使用启动脚本（自动构建 + 启动前后端）
.\scripts\start.bat
```

## 核心工作流程

### 前端开发流程

1. **修改代码** → `src/js/pages/YourPage.jsx`
2. **Vite HMR** → 浏览器自动刷新
3. **验证功能** → 浏览器测试
4. **代码检查** → `npm run lint`
5. **格式化代码** → `npm run format`

### 后端开发流程

1. **修改代码** → `backend-go/internal/yourmodule/service.go`
2. **重新构建** → `go build -o api-monitor.exe ./cmd/api-monitor`
3. **重启服务** → `./api-monitor.exe`
4. **API 测试** → Postman / curl
5. **单元测试** → `go test ./internal/yourmodule`

### Agent 开发流程

1. **修改代码** → `agent-rust/src/*.rs`
2. **编译** → `cargo build`
3. **运行** → `./target/debug/api-monitor-agent --server http://localhost:3000 --server-id 1`
4. **调试** → 查看终端日志

## 常见开发任务

### 1. 添加新的 API 路由

#### 后端 (Go)

**步骤 1**: 创建模块 `backend-go/internal/yourmodule/service.go`

```go
package yourmodule

import (
    "net/http"
    "github.com/iwvw/api-monitor/backend-go/internal/config"
    "github.com/iwvw/api-monitor/backend-go/internal/response"
)

type Service struct {
    cfg config.Config
}

func New(cfg config.Config) *Service {
    return &Service{cfg: cfg}
}

func (s *Service) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    switch r.Method {
    case http.MethodGet:
        s.handleList(w, r)
    case http.MethodPost:
        s.handleCreate(w, r)
    default:
        response.Error(w, http.StatusMethodNotAllowed, "Method not allowed")
    }
}

func (s *Service) handleList(w http.ResponseWriter, r *http.Request) {
    response.OK(w, map[string]interface{}{
        "data": []string{"item1", "item2"},
    })
}
```

**步骤 2**: 注册到 `backend-go/internal/server/server.go`

```go
import "github.com/iwvw/api-monitor/backend-go/internal/yourmodule"

// 在 NewServer 函数中
yourmodule: yourmodule.New(cfg),

// 在 serveGoRoute 函数中
case "/api/yourmodule":
    s.yourmodule.ServeHTTP(w, r)
```

**步骤 3**: 注册路由到 `backend-go/internal/manifest/manifest.go`

```go
{
    Prefix: "/api/yourmodule",
    Module: "yourmodule",
    Owner: OwnerGo,
    Auth: AuthSession,
    ResponseMode: ResponseJSON,
    Description: "Your module description",
}
```

#### 前端 (React)

**步骤 1**: 创建页面 `src/js/pages/YourModulePage.jsx`

```jsx
import { useState, useEffect } from 'react';
import useStore from '@/js/store.js';

export default function YourModulePage() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchData();
  }, []);

  const fetchData = async () => {
    try {
      const res = await fetch('/api/yourmodule', {
        headers: useStore.getState().getAuthHeaders?.() || {},
      });
      const result = await res.json();
      setData(result.data || []);
    } catch (error) {
      console.error('Failed to fetch data:', error);
    } finally {
      setLoading(false);
    }
  };

  if (loading) return <div>Loading...</div>;

  return (
    <div className="p-6">
      <h1 className="text-2xl font-bold mb-4">Your Module</h1>
      <ul>
        {data.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  );
}
```

**步骤 2**: 注册模块到 `src/js/store.js`

```javascript

  // ...现有模块
  yourmodule: {
    name: '你的模块',
    shortName: '模块',
    icon: 'fa-cube',
    description: '模块描述',
  },
};
```

**步骤 3**: 添加路由到 `src/js/App.jsx`

```jsx

// 在路由映射中

  // ...现有路由
  yourmodule: YourModulePage,
};
```

### 2. 添加数据库表

**创建迁移脚本** (在模块初始化时执行):

```go
func (s *Service) initSchema(ctx context.Context) error {
    db, err := s.store.Open(ctx)
    if err != nil {
        return err
    }
    defer db.Close()

    schema := `
    CREATE TABLE IF NOT EXISTS your_table (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        value TEXT,
        created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
        updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    CREATE INDEX IF NOT EXISTS idx_your_table_name ON your_table(name);
    `

    _, err = db.ExecContext(ctx, schema)
    return err
}
```

### 3. 添加定时任务

使用 `cronjobs` 模块:

```go
import "github.com/iwvw/api-monitor/backend-go/internal/cronjobs"

// 在模块初始化时
func New(cfg config.Config, cron *cronjobs.Service) *Service {
    s := &Service{cfg: cfg}
    
    // 注册定时任务
    cron.Register("yourmodule-cleanup", "0 2 * * *", func() {
        s.cleanup()
    })
    
    return s
}

func (s *Service) cleanup() {
    // 清理逻辑
}
```

## 代码规范

### Go 代码规范

1. **包命名**: 小写，无下划线，简洁有意义
2. **函数命名**: 驼峰命名，导出函数首字母大写
3. **错误处理**: 始终检查并处理错误
4. **注释**: 导出函数必须添加注释

**示例**:

```go
// GetAccounts 获取所有账号列表
func (s *Service) GetAccounts(ctx context.Context) ([]Account, error) {
    db, err := s.store.Open(ctx)
    if err != nil {
        return nil, fmt.Errorf("open database: %w", err)
    }
    defer db.Close()

    rows, err := db.QueryContext(ctx, "SELECT id, name FROM accounts")
    if err != nil {
        return nil, fmt.Errorf("query accounts: %w", err)
    }
    defer rows.Close()

    var accounts []Account
    for rows.Next() {
        var acc Account
        if err := rows.Scan(&acc.ID, &acc.Name); err != nil {
            return nil, err
        }
        accounts = append(accounts, acc)
    }

    return accounts, nil
}
```

### JavaScript/React 规范

1. **组件命名**: 大驼峰 (PascalCase)
2. **函数命名**: 小驼峰 (camelCase)
3. **常量命名**: 全大写下划线分隔
4. **使用 Hooks**: 函数组件优先
5. **避免内联样式**: 使用 Tailwind 类名

**示例**:

```jsx
import { useState, useEffect } from 'react';
import { Button } from '@cloudflare/kumo';

const DEFAULT_PAGE_SIZE = 20;

export default function AccountList() {
  const [accounts, setAccounts] = useState([]);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    fetchAccounts();
  }, []);

  const fetchAccounts = async () => {
    setLoading(true);
    try {
      const response = await fetch('/api/accounts');
      const data = await response.json();
      setAccounts(data.accounts || []);
    } catch (error) {
      console.error('Failed to fetch accounts:', error);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="space-y-4">
      {accounts.map((account) => (
        <div key={account.id} className="p-4 border rounded">
          {account.name}
        </div>
      ))}
    </div>
  );
}
```

## 常见问题

### Q1: 前端请求后端 API 时出现 CORS 错误

**A**: 检查 Vite 代理配置 (`vite.config.mjs`):

```javascript
proxy: {
  '/api': {
    target: 'http://127.0.0.1:3000',
    changeOrigin: true,
  },
}
```

### Q2: Go 后端无法连接数据库

**A**: 确保 `DATA_DIR` 目录存在且有写入权限:

```bash
mkdir -p data
chmod 755 data
```

### Q3: Agent 无法连接到服务器

**A**: 检查以下几点:
1. 服务器地址是否正确
2. Agent Key 是否有效
3. 服务器防火墙是否开放端口
4. Engine.IO 服务是否正常运行

### Q4: 前端构建后无法加载资源

**A**: 检查 Vite 配置中的 `base` 路径:

```javascript
export default defineConfig({
  base: '/',  // 确保与部署路径一致
});
```

### Q5: SQLite 数据库锁定错误

**A**: 启用 WAL 模式:

```sql
PRAGMA journal_mode=WAL;
```
