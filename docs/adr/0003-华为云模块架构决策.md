# ADR-0003：华为云模块架构决策

- 状态：已接受
- 日期：2026-09-06

## 决策

API Monitor 新增独立的 `huawei` 云厂商模块，模块 ID 为 `huawei`，作为华为云（Huawei Cloud）的统一管理入口。模块采用**纯 REST API + AK/SK 自研签名**的接入方式，不引入官方 Go SDK 重型依赖，模块结构遵循 Oracle/GCP 模块已验证的多文件分层模板。Flexus L 实例作为组合服务接入，列表走「配置审计」（RMS）`all-resources` 接口，云主机操作复用 ECS API。

### 1. REST 优先，不引入官方 SDK

华为云面向本模块的产品（IAM、ECS、云解析 DNS、VPC/EIP、OBS、配置审计 RMS、BSS）均提供 REST + JSON 接口，统一使用 AK/SK + `SDK-HMAC-SHA256` 签名鉴权。决策使用 Go 标准库 `net/http` 直接调用，理由：

1. 官方 Go SDK（`huaweicloud-sdk-go-v3`）覆盖服务全量 API，依赖链与代码量远大于本模块所需的子集，与本项目「SQLite 单进程、低依赖」的架构定位冲突（与 ADR-0002 对 GCP 的论证一致）。
2. 签名算法简单（HMAC-SHA256），已对照官方 `core/auth/signer/signer.go` 用真实凭证实测打通（见下），手写约 120 行即可覆盖。
3. 与现有 aliyun/tencent 模块的自研签名模式同族（阿里云 HMAC-SHA1 RPC、腾讯 TC3-HMAC-SHA256），代码风格一致。
4. 唯一签名协议例外是 OBS：对象存储 API 不使用 `SDK-HMAC-SHA256`，而是独立的 OBS 签名算法（基于 AK/SK 的 AWS S3 风格变体），需要独立 `obs_auth.go` 签名器（见第 9 节）。

### 2. 凭证：AK 明文 + SK 加密落库

华为云凭证为 AK/SK 对（Access Key ID / Secret Access Key）。决策：

1. `access_key_id`（AK）作为账号标识明文存储（同 Oracle 的 OCID 明文模式），但列表回显时部分掩码。
2. `secret_access_key`（SK）使用现有 `secure.SecureEncrypt` 加密后存入 `huawei_accounts.secret_access_key_encrypted` 列。
3. 不照抄 aliyun/tencent 的明文 token 存储（历史遗留，见 CONTEXT.md）。华为云模块从第一版起遵循加密存储基线，与 oracle/gcp/m365/cloudflare 一致。
4. 读取到签名器前临时解密，签名完成后即丢弃明文（除进程内存缓存必要字段）。

### 3. 站点与区域上下文

华为云分国内站与国际站，API 域名后缀不同（`myhuaweicloud.cn` vs `myhuaweicloud.com`），且资源按 region（区域）+ project（项目）组织：

1. 账号接入时必须选择站点（国内站 / 国际站），默认国内站；站点决定 IAM/资源 API 域名后缀。
2. 区域为项目级上下文：`IAM /v3/projects` 返回账号可见的全部区域项目（实测 16 个国内站项目），项目同时携带 region 名称与 project_id。
3. 账号存 `default_region`（默认区域）+ `default_project_id`（默认项目，可由验证时自动发现或用户指定），资源查询路径带 project_id。
4. 面板路由以查询参数或路径段承载 region/project 上下文（与 GCP 的 zone 语义类似，华为云用 path 段直接承载 project_id 更自然，因 project_id 是稳定 UUID）。

### 4. 模块结构：照抄 GCP/Oracle 模板

```text
backend-go/internal/huawei/
├── service.go            # Service + New + ServeHTTP 路径分发 + open()
├── schema.go             # huawei_accounts 幂等建表
├── account_store.go      # 账号 CRUD + secure 加密 + safeAccount 脱敏
├── types.go              # Account / payload / Normalized* 响应结构
├── client.go             # huaweiRequest REST 封装 + base URL 映射 + 分页聚合
├── auth.go               # AK/SK → SDK-HMAC-SHA256 签名（除 OBS）
├── obs_auth.go           # OBS 独立签名器
├── compute_service.go    # ECS 实例（列表/详情/启停/重启/重置密码/改名/删除）
├── flexus_service.go     # Flexus L 实例（RMS all-resources + ECS 复用）
├── dns_service.go        # 云解析 zone / recordset
├── network_service.go    # EIP / VPC（Phase 2）
├── storage_service.go    # OBS 桶/对象（Phase 3）
├── billing_service.go    # BSS 账单/流量包（Phase 3 可选）
└── service_test.go
```

规模超出单文件承载能力时按资源域继续拆分，禁止把所有逻辑堆进超大 `service.go`。

### 5. 路由与鉴权：Manifest 一行前缀 + AuthSession

- `manifest.go` 新增：`{Prefix: "/api/huawei", Module: "huawei", Owner: OwnerGo, Auth: AuthSession, ResponseMode: ResponseJSON, Description: "Huawei Cloud accounts and resources"}`
- `server.go` 按新模块标准四处改动（import、Server 字段、newServer 实例化、serveGoRoute case）。
- 全部接口走 session auth，写操作（POST/PUT/DELETE）均为登录态用户操作。

### 6. 前端：独立 HuaweiPage，注册进 cloud-vendors 分组

- `src/js/pages/HuaweiPage.jsx`（规模大时按 `src/js/pages/huawei/` 目录拆分）。
- `store.js` 的 `MODULE_CONFIG` + `MODULE_GROUPS` cloud-vendors subgroup 增加条目。
- `MainLayout.jsx` lazy import + `renderActivePage` case + stickyHeaderScrollModule 数组补 `'huawei'`。
- `Icons.jsx` 品牌图标（先用 `Cloud` 兜底，属允许的品牌色例外组，华为云 simple-icons 就绪后替换）。
- UI 全部 Kumo 组件、中文文案，高风险动作走 `dialog.deleteResource` / Kumo `DeleteResource`，表格用 `AppTable columns` 语义列角色，遵循《新模块接入指南》《Kumo UI 规则》《语义化表格布局与移动端适配》全部 UI 约束。

### 7. Flexus L 实例：组合服务接入策略

Flexus L（Flexus 应用服务器 L 实例）是华为云轻量应用服务器产品线（对标阿里云轻量 SWAS、腾讯云 Lighthouse），但**没有独立 API**，是跨服务组合：

1. **实例（套餐）列表**：走「配置审计」RMS（Resource Manager Service）的 `GET /v1/resource-manager/domains/{domain_id}/all-resources?type=hcss.l-instance`，实测 `rms.myhuaweicloud.cn`（全局端点）可用，返回套餐 ID/名称/区域/规格编码/订单号/套餐内资源（云主机、流量包）。
2. **云主机操作**：复用 ECS API。实测证明 Flexus L 套餐内云主机（`huaweicloudinternal_ecs_instance` 的 `physical_resource_id`）在 ECS `cloudservers/detail` 列表可见、`ShowServer` 可查详情，故启停/重启/重置密码/改名直接走 ECS 接口。
3. **续订/退订/流量包**：走 BSS 费用中心（域名可达，路径以正式文档为准，Phase 3 可选）。
4. 产品上 Flexus L 在华为云模块内做独立 Tab/分类展示（套餐信息 + 云主机联动），实现上列表与操作分层。

### 8. 签名实现要点（已实测校准）

对照官方 `core/auth/signer/signer.go`（huaweicloud-sdk-go-v3），三处容易踩坑的规则：

1. **canonicalURI 强制尾斜杠仅用于签名**：签名时 CanonicalURI 对路径逐段 `escape`（保留 `A-Za-z0-9_-~.`，其余 `%XX` 大写）后拼接，若末尾无 `/` 则补 `/`；但**实际发出的 HTTP 请求 URL 用原始路径**（不加尾斜杠）。
2. **canonicalRequest 含 6 段**：`method\ncanonicalURI\ncanonicalQueryString\ncanonicalHeaders\nsignedHeaders\ncontentHash`。第 6 段 contentHash 对 JSON body 取 `sha256(body)`，空 body 为 `sha256("")`（`e3b0c442...`）；当 Content-Type 非 `application/json`/`application/bson` 时固定为 `UNSIGNED-PAYLOAD`。
3. **签名 key 直接用 SK**：`signature = HMAC-SHA256(SK, stringToSign)`，无 AWS 式 kDate/kRegion/kService 派生链；`stringToSign = "SDK-HMAC-SHA256\n{x-sdk-date}\nsha256(canonicalRequest)"`，x-sdk-date 格式 `YYYYMMDDTHHMMSSZ`（UTC）。

签名 Header：`Authorization: SDK-HMAC-SHA256 Access={AK}, SignedHeaders=host;x-sdk-date, Signature={sig}`。

### 9. OBS 独立签名器

OBS 对象存储 API 不用 `SDK-HMAC-SHA256`，采用独立 OBS 签名协议（AK/SK 参与、内容哈希、`Date`/`x-obs-date` 头）。决策：

- `obs_auth.go` 单独实现 OBS 签名器，覆盖桶列表/桶 CRUD/对象浏览/上传/下载/删除。
- OBS 域名为 `obs.{region}.myhuaweicloud.cn`，访问桶内对象走 `https://{bucket}.obs.{region}.myhuaweicloud.cn`。
- 第一版 OBS 能力以只读浏览 + 简单上传/删除为主，签名器在 Phase 3 实现并按官方文档校准。

### 10. 与现有模块的边界

1. **不并入 `server` 模块**：华为云是云资源控制面，与主机纳管（Agent/SSH/Docker）职责不同，与 Oracle/GCP 决策一致。
2. **与模型网关互不影响**：网关接入的是 OpenAI/DeepSeek 等模型，华为云模块不涉及模型调用。
3. **不做多租户 RBAC**，模块内不建独立权限模型。
4. 华为云实例→`server` 模块导入为后续弱集成，不作为第一版前置条件。
5. Flexus L 的续订/退订为费用敏感操作，第一版默认只读（流量包剩余量），续订/退订不在第一版开放。

### 11. 异步操作语义

华为云 ECS 的批量启停/重启等接口返回同步结果（`POST /v1/{project_id}/cloudservers/action`），创建实例、部分 VPC 操作为异步任务（返回 `job_id`）。

- 后端对同步操作直接返回结果；对异步任务返回 `job_id`，前端展示「指令已下发」并通过任务查询接口（`GET /v1/{project_id}/jobs/{job_id}`）或列表刷新观察最终状态。
- 第一版不实现长轮询/SSE，与 Oracle/GCP 模块一致。

## 后果

- 优点：零新增 Go 依赖（签名用标准库 `crypto/hmac`），模块轻量、可测、与现有架构完全一致；SK 加密落库建立凭证安全基线；Flexus L 复用 ECS API 降低实现成本。
- 缺点/代价：华为云 REST 响应需要手写归一化层（Normalized* 结构）；OBS 独立签名协议增加少量实现面；BSS 费用接口路径与权限需按正式文档逐项校准。
- 风险与缓解：
  - AK/SK 泄露风险：SK 加密 + 列表脱敏 + 日志不打印 SK（同 Oracle 安全要求）。
  - 签名错误：对照官方 signer 源码 + 真实凭证冒烟（已在本决策落地时实测打通 IAM/ECS/DNS/RMS）。
  - 国内站/国际站域名差异：站点字段驱动 base URL 映射，避免硬编码。
  - BSS 接口路径不确定：Phase 3 按官方 API 文档逐项校准，未校准前不开放写接口。
